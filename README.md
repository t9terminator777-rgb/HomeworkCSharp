# Домашние задания по C#

Одно консольное приложение с меню, в котором собраны все восемь задач. Запуск из папки проекта: `dotnet run`.

## Задания в меню

1. Расчёт аренды лыж или сноуборда, включая страховку.
2. Учёт примерного количества чистого спирта в введённых порциях и предупреждение по заданному пользователем порогу.
3. Определение возрастного периода и вывод рекомендации.
4. Расчёт недельных часов тренировок гладиатора по выбранным дням и типу тренировки.
5. Оценка годовых расходов BMW M5 F90 на топливо и страховку.
6. Добавление клиентов салона, сохранение данных в JSON и показ списка клиентов за сегодня.
7. Расчёт веса и стоимости выбранной экипировки гладиатора.
8. Подсчёт побед, поражений и процента побед гладиатора.

## Учебные допущения

- В программе аренды и расчёта экипировки используются примерные учебные цены и веса; их можно изменить в коде.
- Любое количество алкоголя несёт риск для здоровья; безопасной дозы нет. В программе порог — только выбранный пользователем сигнал уведомления, а расчёт чистого спирта приблизительный. Источник: https://www.who.int/news-room/fact-sheets/detail/alcohol
- Расходы BMW включают только топливо и страховку, без ремонта, налогов и амортизации.
- Файл `salon_clients.json` хранится локально и исключён из Git через `.gitignore`.
- Возрастные границы в пункте 3 выбраны для учебного примера.

## Что показывает приложение

Каждая задача оформлена отдельным классом, реализующим интерфейс `IHomeworkTask`. Интерфейс задаёт свойство `Title` и метод `Run()`. Для ввода используются отдельные методы проверки целых чисел, денежных/дробных значений, текста и ответов «да/нет».
